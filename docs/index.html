Fair questions

Is it really free?+

Yes. AGPL-3.0 licensed, self-host it on your own hardware forever. Unlimited forms, unlimited responses, unlimited everything.

Can I use it for my business?+

Absolutely — client forms, internal surveys, event RSVPs, lead capture. If you modify Formo itself and serve it to others, AGPL asks you to share those modifications.

Where does response data live?+

In a single SQLite file inside the container/volume you control. Back it up by copying one file. No third parties involved.

What's on the roadmap?+

File uploads, Zapier/n8n integrations, multi-user teams, partial response saving. Skip logic and Slack/Discord notifications are already in. Contributions welcome — it's your repo too.
